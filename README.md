# Лабораторна робота №3
**Дисципліна:** Алгоритмізація та програмування  
**Тема:** Реалізація алгоритмів з розгалуженням мовою C++  
**Варіанти:** 34, 35, 7  

## Опис проекту
Програма містить консольне меню (`switch`), що дозволяє обирати виконання наступних завдань:
1. **Завдання 1 (Варіант 34):** Обчислення значення функції $v(x)$ з розгалуженою структурою.
2. **Завдання 1 (Варіант 35):** Обчислення значення функції $u(x)$ з перевіркою умов.
3. **Завдання 2 (Варіант 7):** Визначення попадання точки з координатами $(x, y)$ у задану геометричну область (варіант 7).

У кожному завданні реалізовано захист від невірних введених даних (`cin.fail()`).
